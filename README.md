Repository supporting bachelor thesis developed by Floor Boereboom with supervision of Marvin Martens. 
Transcriptomic data generated from Pt-based compounds exposed cultured proximal tubule epithelial cells (ciPTEC) were used as input for the analysis
Resulting normalized transcriptome count matrix and corresponding metadata table that were preprocessed in the R-ODAF Shiny app
Differential exppresed genes (DEGs) for each Pt-based compound were obtained 

Merged DEGs: Merged the three different DEGs tables together to obtain a core transcriptional response
Overlapping DEGs: the number of DEGs overlapping between two Pt-based compounds were the output
PCA: created a PCA plot with explained varience per principal component
Ratio up- and downregulated genes: The percentage of downregulated genes in the overall dataset was calculated
